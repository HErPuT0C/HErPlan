# ADR-006. Генерация PDF

Статус: принято (2026-10-18, Г1)
Дата: 2026-10-18
Задача плана: Ф0-09

## Контекст

Документы (GDD, питч, вики) экспортируются в PDF с оглавлением, полями, номерами страниц и кириллицей, без лишних разрывов страниц (`FR-DOC-06`, критерии в `docs/spec.md`, раздел 8). В редакторе документ — поток (ADR-003), страницы появляются только при экспорте.

## Варианты

1. **pdfmake** (MIT): описание документа в JSON → PDF; оглавление с номерами страниц, таблицы, изображения, колонтитулы, встраивание шрифтов. Чистый JavaScript, работает офлайн в любой оболочке.
2. Печать страницы средствами браузера (`printToPDF` в Electron; в WebView2 есть аналог, но Tauri его напрямую не даёт): вёрстка через CSS. Оглавление с номерами страниц сделать трудно, поведение зависит от оболочки.
3. Typst как библиотека в Rust: лучшая типографика, но большой объём интеграции и свой язык разметки.

## Прототип

`prototypes/pdf/make-pdf.mjs`, около 150 строк: Markdown со вставками HErPlan → токены `marked` → описание pdfmake → PDF.

Результат на тестовом документе (8 разделов, таблицы, списки, цитаты, изображение, обе разновидности вставок):
- 6 страниц A4 за 0.3 с;
- оглавление с номерами страниц (заголовки 1–2 уровня);
- шрифт Roboto встроен подмножеством; кириллица выделяется и ищется (`pdftotext` находит все 40 вхождений «Мира»);
- вставки заменены текущими значениями из базы (имя, число, роль);
- заголовок не может остаться последней строкой страницы (правило `pageBreakBefore`);
- сеть отключена политикой `setUrlAccessPolicy`: PDF не может ничего скачать.

## Решение

**pdfmake.** Выполняется в фоне, чтобы не тормозить интерфейс на больших документах.

## Последствия

- Шрифты по умолчанию — Roboto (Apache 2.0, разрешительная лицензия). Выбор шрифта пользователем (`FR-DOC-01`) потребует встраивать и другие файлы шрифтов; системные шрифты Windows встраивать нельзя из-за их лицензий.
- Набор блоков в PDF ограничен тем, что умеет преобразователь; новые блоки редактора добавляются в него вместе с автотестом (сверка текста через `pdftotext`).
