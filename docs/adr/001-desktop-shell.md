# ADR-001. Оболочка Windows-приложения

Статус: предложено (ждёт замеров на ПК владельца, задача Ф0-12)
Дата: 2026-10-18
Задача плана: Ф0-03

## Контекст

HErPlan — настольное приложение только для Windows (решение владельца), лёгкое для слабых ПК (`NFR-01`, `NFR-05`), с удобным установщиком и деинсталлятором, который не трогает проекты (`FR-DIST-01..04`). Нужны перетаскивание файлов и папок из проводника, корзина Windows, быстрая и надёжная работа с файлами (ADR-004). Интерфейс опирается на веб-компоненты: редактор текста на ProseMirror (ADR-003) и холст (ADR-002).

## Варианты

1. **Tauri 2**: интерфейс в системном WebView2 (встроен в Windows 10/11), логика на Rust. Установщик NSIS с установкой для текущего пользователя и деинсталлятором из коробки.
2. **Electron**: собственный Chromium и Node.js внутри приложения. Самая зрелая платформа, одинаковый движок везде, но тяжелее по размеру и памяти.
3. **.NET + Avalonia**: нативный интерфейс. **Отброшен без прототипа:** для него нет зрелого редактора форматированного текста с Markdown и своими вставками, а это самый рискованный компонент (TR1). Пришлось бы писать редактор с нуля. Отступление от плана Ф0-03 («замеры по каждому кандидату») сделано сознательно.

Прототипы: `prototypes/shell-tauri`, `prototypes/shell-electron`. Оба загружают одну и ту же сборку `prototypes/web` (холст и редактор).

## Замеры

### Сквозная проверка (контейнер разработки, Linux)

Обе оболочки запускаются, передают отчёт в файл через мост (`report`) и закрываются (`quit`). В Tauri доступны API версии приложения при минимальных разрешениях (`core:default`).

### CI: Windows (`windows-latest`, без видеокарты)

Заполняется по прогону workflow `prototypes`: размер установщика, место на диске, время до появления окна, память в простое (вся группа процессов), кадры в секунду при программной отрисовке, чистота удаления.

### ПК владельца

Заполняется по отчёту владельца (задача Ф0-12): реальная видеокарта, плавность холста, поведение текста.

## Решение

Будет принято после замеров. Предварительно — **Tauri 2**: меньше места и памяти, установщик и деинсталлятор из коробки, файловая логика (атомарная запись, копии, индексы) на Rust, где она уже проверена прототипом (ADR-004).

## Последствия

- Интерфейс работает в WebView2 (это Chromium, как в Edge); его версия обновляется вместе с Windows, а не с нашим приложением. Нужна проверка на минимальной поддерживаемой версии WebView2.
- Установщик скачивает WebView2, если его нет (редко: только на старых Windows 10).
- Логика ядра на Rust тестируется в контейнере на Linux; интерфейс — в headless Chromium (Playwright); итоговая проверка — на Windows у владельца.
