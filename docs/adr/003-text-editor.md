# ADR-003. Редактор текста

Статус: предложено (ждёт проверок владельца на Windows, задача Ф0-12)
Дата: 2026-10-18
Задача плана: Ф0-05

## Контекст

Документы хранятся в Markdown со своими вставками (`FR-DOC-01`). Требования к поведению текста (`FR-DOC-02`): отмена без «возвратов», вставка из Word и браузера без поломки ввода, контекстное меню, русский ввод и проверка орфографии. Вставки из базы данных должны обновляться сами (`FR-DOC-03`). Это самый рискованный компонент (TR1 в `docs/spec.md`).

## Варианты

1. **TipTap 3** (ProseMirror, MIT) с официальным расширением `@tiptap/markdown`.
2. Milkdown (ProseMirror, Markdown-ориентированный, MIT).
3. CodeMirror 6 с живым предпросмотром (как исходный режим Obsidian).
4. Lexical (Meta, MIT).

Прототипировался только вариант 1: самая большая экосистема (таблицы, изображения, вставка из Word), зрелая модель отмены ProseMirror, официальная поддержка Markdown с собственными токенами. К остальным вернёмся, только если TipTap не пройдёт проверки.

Прототип: `prototypes/web/src/editor/`. Синтаксис вставок-кандидат: `[[ent:mira|Мира]]` (ссылка; подпись после `|` делает файл читаемым в Obsidian) и `{{ent:mira.доверие}}` (живое поле). Окончательный синтаксис — ADR-004.

## Замеры и проверки

Автоматически (headless Chromium, CI):
- Markdown → редактор → Markdown даёт тот же текст ✅.
- **Найден и исправлен дефект библиотеки:** `@tiptap/markdown` 3.32 применяет жирный, курсив и зачёркивание только к обычному тексту. Поэтому `**[[ent:mira|Мира]]**` терял жирный при открытии файла, то есть менялся текст пользователя. Исправление — 30 строк: `markdown-marks.ts` дополняет разбор, вставки сами оборачивают себя при сохранении. Автопроверка в прототипе ловит регрессию. Это нужно сообщить разработчикам TipTap.
- Живые вставки обновляются сразу при изменении данных ✅.

Вручную на Windows (владелец, вкладка «Текст» прототипа): вставка из Word и браузера, ввод после Ctrl+V, отмена и повтор, контекстное меню, русский ввод и орфография, «@» для вставки сущности, подсветка кнопок панели. Заполняется по отчёту.

## Решение

Предварительно **TipTap 3 + `@tiptap/markdown`** с нашим расширением для вставок. Окончательно — после проверок владельца.

## Последствия

- Обновления `@tiptap/markdown` проверяются автотестами на сохранение форматирования вокруг вставок.
- Постраничная разметка в редакторе не нужна: документ — поток, страницы появляются только в PDF (ADR-006).
