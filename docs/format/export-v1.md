# Экспорт сценария в JSON, версия 1

Статус: v1 (задача Ф3-14, `FR-EXP-01`). Машиночитаемая схема: [`export-v1.schema.json`](export-v1.schema.json) (JSON Schema 2020-12). Код: `app/src/story/export.ts`.

Экспорт — один файл для игровых движков: сценарий (все главы), переменные и карточки мира. Он не заменяет папку проекта: из него нельзя открыть проект, и в нём нет стикеров, групп и оформления холста.

В HErPlan: вкладка «Сценарий» → «Экспорт JSON».

## Принципы

1. **Ссылки по ID**, как в проекте: узлы, связи, переменные и карточки ссылаются друг на друга идентификаторами, а не именами.
2. **Выражения дважды:** исходный текст (`source`, как его написал сценарист) и дерево разбора (`ast`). Проигрывателю в движке достаточно обойти небольшое дерево, разбирать текст не нужно ([ADR-005](../adr/005-expression-language.md)).
3. **Сломанное выражение не теряется:** если текст не разбирается, `ast` (или `effects`) равен `null`, а `source` сохраняется. Проверки проекта в HErPlan показывают такие места заранее.
4. **Новые поля могут появиться** в следующих версиях экспорта без смены `version`; удаление или переименование поля — только с новой версией. Читатель должен пропускать незнакомые поля.

## Верхний уровень

```json
{
  "format": "herplan-export",
  "version": 1,
  "exportedWith": "0.2.0",
  "exportedAt": "2026-10-18T10:00:00Z",
  "project": { "id": "k3v9q0d2m7x1c8bz", "name": "Мельница" },
  "variables": [ … ],
  "entities": [ … ],
  "story": { "root": "g-root…", "graphs": [ … ] }
}
```

## Переменные

```json
{ "id": "v-mira…", "name": "доверие", "fullName": "Мира.доверие", "type": "int", "initial": 0,
  "scope": "project", "owner": "ent-mira…", "values": null, "description": "" }
```

| поле | значение |
| --- | --- |
| `name` | имя переменной |
| `fullName` | имя, как оно пишется в выражениях: у переменной карточки — `Карточка.имя` |
| `type` | `bool`, `int`, `float`, `string`, `enum` (список значений), `entity` (карточка мира) |
| `initial` | начальное значение; у `entity` — ID карточки или `null` |
| `scope` | `"project"` или `{ "graph": "<id главы>" }`: переменная главы видна в ней и во вложенных главах и сбрасывается к начальному значению при входе в главу |
| `owner` | ID карточки-владельца или `null` |
| `values` | значения `enum`, иначе `null` |

В выражениях переменная `entity` сравнивается с **именем** карточки: `спутник == «Борис»`.

## Карточки мира

```json
{ "id": "ent-mira…", "type": "character", "name": "Мира", "description": "Травница", "image": "assets/world/mira.png" }
```

`type`: `character`, `location`, `item`. `image` — путь внутри папки проекта или `null`.

## Графы сценария

`story.root` — ID обзора глав (граф `kind: "story"`). Каждая глава — отдельный граф (`kind: "chapter"`) с `parent` — узлом-главой, которому он принадлежит:

```json
{ "id": "g-ch1…", "kind": "chapter", "name": "Глава 1. Мельница",
  "parent": { "graph": "g-root…", "node": "r-ch1…" }, "start": "a-start…",
  "nodes": [ … ], "edges": [ … ] }
```

`start` — первый узел `start` графа, откуда начинается прохождение главы, или `null`.

### Узлы

Общие поля: `id`, `kind`, `title`, `text`, `x`, `y` (положение на холсте, можно игнорировать), необязательные `comment` и `plotRole` (`consequence` или `payoff`).

| `kind` | что делает при прохождении | свои поля |
| --- | --- | --- |
| `start` | точка входа графа, сразу идёт дальше | — |
| `scene` | показывается игроку | — |
| `dialogue` | показывается игроку | `lines: [{ id, speaker, text }]`, `speaker` — ID персонажа или `null` (рассказчик) |
| `choice` | игрок выбирает вариант | `options: [{ id, text, condition, effects }]` |
| `condition` | ветвление: выход `yes` или `no` | `condition` |
| `effect` | применяет эффекты и идёт дальше | `effects` |
| `butterfly` | эффект бабочки: применяет эффекты и показывается | `effects`, `consequences: [{ graph, node }]` |
| `gun` | чеховское ружьё: деталь-завязка | `payoffs: [{ graph, node }]` — где «выстрелит» |
| `jump` | переход в любой узел проекта | `target: { graph, node }` или `null` |
| `chapter` | вход в граф главы | `graph` — ID графа главы, `image` |
| `end` | конец главы: возврат к узлу-главе и дальше по его выходам; конец обзора глав — конец истории | — |
| `character`, `location`, `item` | ссылка на карточку мира; показывается | `entity` — ID карточки или `null` |
| `node` | обычный узел без смысла для сюжета; показывается | — |

`consequences` и `payoffs` — сюжетные связи, а не переходы: по ним прохождение не идёт.

### Связи

```json
{ "id": "e…", "from": "a-check…", "fromPort": "yes", "to": "a-hurt…", "label": null,
  "condition": { "source": "доверие > 2", "ast": { … } } }
```

`fromPort`: у выбора — ID варианта, у условия — `yes` или `no`, у остальных — сторона узла (`in`, `out`, `top`, `bottom`), для смысла не важна. Связь с ложным `condition` недоступна; `condition: null` — всегда доступна.

## Выражения

Условие:

```json
{ "source": "золото >= 5", "ast": { "kind": "binary", "op": ">=",
  "left": { "kind": "var", "name": "золото" }, "right": { "kind": "literal", "value": 5 } } }
```

Эффекты:

```json
{ "source": "есть_ключ = истина; золото -= 5", "effects": [
  { "target": "есть_ключ", "op": "=", "value": { "kind": "literal", "value": true } },
  { "target": "золото", "op": "-=", "value": { "kind": "literal", "value": 5 } } ] }
```

Узлы дерева:

| `kind` | поля |
| --- | --- |
| `literal` | `value`: число, строка или `true`/`false` |
| `var` | `name` — `fullName` переменной |
| `unary` | `op`: `not` или `neg`; `arg` |
| `binary` | `op`: `or`, `and`, `==`, `!=`, `<`, `<=`, `>`, `>=`, `+`, `-`, `*`, `/`, `%`; `left`, `right` |

Правила вычисления, как в прохождении HErPlan:

- `and` и `or` — с коротким замыканием; `+` для двух строк склеивает их.
- Деление и остаток от деления на ноль дают `0`.
- Эффекты применяются по порядку; результат для переменной `int` отбрасывает дробную часть.
- Пустое условие (`null`) — истина.

## Как пройти сценарий в движке

1. Начать с `start` графа `story.root`; стек глав пуст.
2. Узлы `start`, `condition`, `effect`, `jump` и `chapter` проходятся без участия игрока. `chapter` кладёт себя в стек и переходит к `start` своего графа; `end` снимает узел-главу со стека и продолжает по его выходам; `end` при пустом стеке — конец истории.
3. На остальных узлах игрок видит содержимое. Дальше — по связям, чьи условия истинны (у `choice` — по связи выбранного варианта, его условие показа должно быть истинным, эффекты применяются при выборе).

Эталонный сценарий из 50 узлов и его маршрут — в `app/src/story/sample.ts` и `story.test.ts`.
