# Диалоги для игры (с версии 0.8)

Здесь описано всё, что HErPlan хранит в диалоге сверх сюжета, чтобы разговор можно было перенести в игру без вопросов: целиком, одним узлом или одной репликой. Данные лежат в тех же файлах проекта, что и раньше ([project-v1.md](project-v1.md)); ничего из прежнего не переименовано и не удалено, все новые поля необязательные.

Кто что пишет:

| Файл | Пишет | Читает |
| --- | --- | --- |
| `data/graphs/<id>.json` — разговор | HErPlan | сторона игры |
| `data/entities/<id>.json` — персонажи и предметы | HErPlan | сторона игры |
| `data/variables.json` — переменные | HErPlan | сторона игры |
| `data/dialogue_palette.json` — палитра игры | сторона игры | HErPlan |
| `data/dialogue_import.json` — что перенесено | сторона игры | HErPlan |
| `data/dialogue_translations.json` — переводы реплик | сторона игры | HErPlan |

HErPlan читает файлы игры при открытии проекта, когда окно снова получает фокус и по кнопке «Проверить диалог». Сам он их не меняет.

## Имена в игре

Поле `key` — латинское имя (`^[a-z][a-z0-9_]*$`), под которым объект известен игре:

- у графа (`data/graphs/<id>.json`): `"key": "skeleton_talk"`. Переносятся только графы с именем;
- у карточки персонажа или предмета (`data/entities/<id>.json`): `"key": "skeleton"`, `"key": "ring_first"`;
- у переменной (`data/variables.json`): `"key": "skeleton_respect"`.

Имя и номера (`id`) реплик и вариантов не меняются, когда правят текст. Имя меняют только руками, и HErPlan об этом предупреждает.

## Реплика

Реплика — элемент `lines` узла `dialogue`. Говорящий (`speaker`) — id карточки персонажа; с 0.8.1 рассказчик — `"narrator"`, а `null` значит «говорящий не выбран» (редактор показывает «кто говорит?», «Проверить диалог» — предупреждение). К `id`, `speaker`, `text` добавились:

| Поле | Значение |
| --- | --- |
| `style` | стиль всей реплики, `id` из палитры `styles` |
| `face` | лицо говорящего, `id` из `faces` |
| `gesture`, `emote` | жест и эмоция: `id` из `gestures` / `emotes` — строкой, либо `{ "id": "question", "to": "<id карточки>" }`, если они обращены к другому участнику |
| `auto` | через сколько секунд реплика идёт дальше сама; поля нет — ждёт нажатия |
| `interrupt` | окно перебивания в секундах; поля нет — как решит игра, `0` — перебить нельзя |
| `condition` | условие показа (то же выражение, что у варианта выбора); пусто — показывать всегда |
| `effects` | эффекты после реплики |
| `actions` | действия игры, см. ниже |
| `note` | заметка для перевода; в игру не идёт |
| `interruptExit` | `true` — у реплики на холсте есть выход «перебили». Нужен только редактору |
| `edited` | когда реплику правили в последний раз (ISO 8601). Нужен только редактору |

Выход «перебили»: связь из узла-диалога, у которой `from.port` — `id` реплики. Обычный выход диалога — как раньше, порт `out` (или `top`, `bottom`).

## Оформление слов и метки между словами

Лежат в поле узла `marks`, рядом с литературными приёмами (`gun`, `butterfly`), и отличаются полем `device`. У них нет `links`, `note` и `variables`; вместо этого — `props`.

```json
"marks": [
  { "id": "…", "device": "style", "anchor": { "kind": "line", "id": "l1" },
    "range": { "start": 4, "end": 14, "quote": "потревожил" },
    "props": { "bold": true, "color": "#ff5544", "effect": "shake" } },
  { "id": "…", "device": "cue", "anchor": { "kind": "line", "id": "l1" },
    "range": { "start": 14, "end": 14, "quote": "" },
    "props": { "pause": 0.4 } }
]
```

`range.start` и `range.end` — смещения в `text` реплики в единицах UTF-16 (как индексы строк в JavaScript); `quote` — сам фрагмент. Метки могут вкладываться и пересекаться.

**`style`** — оформление слов. В `props` любые из полей: `style` (`styles`), `color` (`#rrggbb`), `size` (`sizes`), `bold`, `effect` (`effects`), `speed` (во сколько раз быстрее печатать), `reveal` (`reveals`).

**`cue`** — что-то происходит в точке между словами: `start` равен `end`. В `props` ровно одно из: `pause` (секунды), `shake` (сила), `sound` (`sounds`), `gesture`, `emote`, `face` (держится до конца реплики) — эти три строкой или `{ id, to }`; `to` — кто это делает, если не говорящий (с 0.8.1 и у `face`).

С 0.8.1 («Редактор реплик», раздел 3) в файле не бывает пустого:

- метки-точки стоят только внутри текста (`start` больше 0). Что действует с начала реплики — поля реплики `style`, `face`, `gesture`, `emote`. Старые метки эмоции, жеста и лица в начале реплики при открытии проекта переносятся в эти поля, если поле пустое; если занято — метка остаётся, и редактор показывает её красной;
- пометка оформления без единого свойства и метка без значения (`"emote": ""`) не сохраняются; пометка, у которой убрали все свойства, удаляется;
- две пометки оформления на один и тот же кусок склеиваются в одну.

## Выбор

У узла `choice`: `timer` — секунды на выбор (поля нет — без таймера; когда время вышло, игра берёт вариант, на котором стоит игрок, отдельного выхода нет) и `checkpoint: true` — сохранить игру перед выбором.

У варианта (`options[]`), кроме `id`, `text`, `condition`, `effects`:

| Поле | Значение |
| --- | --- |
| `secret` | `true` — игрок вариант не видит; срабатывает, когда вышло время. Не больше одного на выбор, текст не обязателен |
| `once` | `true` — показать один раз |
| `actions` | действия игры |
| `note` | комментарий автора; в игру не идёт |

Вариантов может быть больше четырёх.

## Узел «Отдать вещь»

`"kind": "give"`. Игрок выбирает, что отдать.

| Поле | Значение |
| --- | --- |
| `title` | заголовок меню; пусто — «Что отдать?» |
| `store` | `id` переменной, в которую записать отданное (необязательно) |
| `keep` | `id` переменной-списка, в который отданное добавить (необязательно) |
| `effects`, `actions` | что происходит, когда вещь отдана |

Три выхода — связи с `from.port`: `given` (отдал), `cancel` (отказался), `empty` (давать нечего). Если из `empty` связи нет, игра идёт туда же, куда `cancel`.

## Действия игры

Поле `actions` — список у реплики, варианта, узла `effect` и узла `give`. Переменные по-прежнему меняются через `effects`.

```json
"actions": [ { "type": "take_item", "ref": "<id предмета>" } ]
```

| `type` | Что делает | Поля |
| --- | --- | --- |
| `give_item`, `take_item` | дать герою предмет, забрать | `ref` — `id` карточки предмета |
| `hire`, `dismiss` | нанять напарника, отпустить | `ref` — `id` карточки персонажа |
| `list_add` | добавить значение в переменную-список | `ref` — `id` списка; `item` — `id` предмета, либо `value` — свой текст |
| `give_list` | отдать герою всё из списка и очистить его | `ref` — `id` списка |
| `save` | сохранить игру | — |
| `event` | произвольное событие | `value` — ключ, который знает игра |
| `start_quest` | начать задание (на будущее) | `value` — ключ |

## Условия

Выражения остаются текстом ([ADR-005](../adr/005-expression-language.md)). К ним добавились четыре слова; в скобках имя пишется так, как оно записано в базе HErPlan, пробелы допустимы:

| Слово | По-английски | Смысл | Что в скобках |
| --- | --- | --- | --- |
| `есть(Первое кольцо)` | `has(…)` | у героя есть вещь | имя карточки предмета |
| `нанят(Тень)` | `hired(…)` | напарник нанят | имя карточки персонажа |
| `видел(l3)` | `seen(…)` | игрок видел реплику или выбирал вариант | `id` реплики или варианта |
| `непусто(подношения)` | `notempty(…)` | в списке что-то есть | имя переменной-списка |

Сочетаются как обычно: `и`, `или`, `не`, скобки. Чтобы получить `id` вместо имени, найдите карточку или переменную с этим именем; в [экспорте](export-v1.md) это уже сделано (поле `ref` узла `call`). При переименовании карточки или списка HErPlan переписывает имя во всех условиях.

## Переменная

В `data/variables.json` у переменной добавились: `key` — имя в игре; `memory` — где игра хранит значение: поля нет или `"world"` — в сохранении, `"game"` — «игра помнит», вне сохранений; и тип `"type": "list"` — список, который наполняет игра (действие `list_add`, поле `keep` узла «Отдать вещь»). У списка нет начального значения (`initial: null`); в выражениях его можно только спросить через `непусто()`.

## Карточки

В файле карточки, рядом с `name`, только те поля, что заданы:

| Поле | У кого | Значение |
| --- | --- | --- |
| `key` | персонаж, предмет | имя в игре |
| `bubble` | персонаж | форма пузыря, `id` из `bubbles` |
| `voice` | персонаж | голос, `id` из `voices` |
| `pitch` | персонаж | высота голоса, `1` — как записан |
| `faces` | персонаж | список `id` из `faces`: какие лица для него нарисованы |

Цвет персонажа — обычное поле карточки (`values`), как и раньше.

## Наборы реплик

Граф с `"kind": "barks"`: только узлы `dialogue`, связей нет. У узла поле `when` — «когда звучит», пока просто текст. В сюжете такой граф принадлежит узлу `"kind": "barks"` (его поле `graph`), как граф главы — узлу `chapter`.

## Палитра игры: `data/dialogue_palette.json`

Её делает сторона игры (Claude) из файлов игры и обновляет сама; HErPlan читает её при открытии проекта, когда окно снова в фокусе и каждые несколько секунд, пока окно открыто. С 0.8.1 значения в редакторе выбираются только из её списков; текстом — только если файла нет (поле в жёлтой рамке). Значение, которого в палитре больше нет, остаётся в файле диалога и показывается в красной рамке «нет в игре». Пункт «— нет —» убирает поле из файла.

Списки, из которых автор выбирает в редакторе. У записи `id` (попадает в файл диалога), `name` (что видит автор) и необязательные `color` (`#rrggbb`) и `hint`. Запись можно дать и просто строкой — тогда `id` и `name` совпадают.

```json
{
  "styles":   [ { "id": "whisper", "name": "Шёпот", "color": "#7fb2ff", "hint": "тихо, мелко" } ],
  "sizes":    [ { "id": "small", "name": "мелко" }, { "id": "big", "name": "крупно" } ],
  "reveals":  [ { "id": "letter", "name": "по буквам" } ],
  "effects":  [ { "id": "shake", "name": "дрожь" } ],
  "bubbles":  [],
  "faces":    [],
  "gestures": [],
  "emotes":   [],
  "voices":   [],
  "sounds":   []
}
```

Кроме этих списков (с 0.8.1):

- у записи `emotes` — `icon: { image, frame, w, h }`: кадр `frame` размером `w × h` в полосе-картинке; у `voices` и `sounds` — `sound`, файл звука. Пути — от папки `data/`;
- `speakers` — кто говорит в игре: `{ id, name, color, bubble, voice, faces: [id лиц] }`. Карточка персонажа связана с ним по «Имени в игре» (`key`); лица реплики — только из `faces` её говорящего; рассказчик — `id: "narrator"`;
- `actions` — действия игры: `{ id, name, ref }`, где `ref` — `item`, `character`, `variable`, `text` или нет. Если список есть, «+ Действие» предлагает его, иначе — действия HErPlan (таблица выше);
- `preview` — всё, чтобы показать реплику как в игре: шрифт (`font`), числа текста (`text`: цвет, ширина, скорость, паузы, тряска, бипы), что делают стили с буквами (`styles[].props`), параметры эффектов (`effects[].params`), жесты, значок, говорящие со спрайтами, пузырь, осыпание. Его описывает документ игры «Редактор реплик», раздел 7; HErPlan берёт оттуда числа для просмотра. Одно отличие от раздела 7.1 с 0.8.2 (по решению владельца, игра меняется так же): эффекты (`fx`) стиля и пометки **складываются** — к уже действующим добавляются новые, без повторов; остальные свойства заменяют прежние. «Крик» внутри реплики в «Гневе» — оранжевый, жирный, словами, с толчком и с дрожью.

Файла нет — списки пусты, и значения пишутся текстом.

## Статус переноса: `data/dialogue_import.json`

```json
{ "graphs": { "<id графа>": {
  "key": "skeleton_talk", "at": "2026-11-12T10:00:00Z", "lines": 42,
  "problems": [ { "node": "<id узла>", "line": "l3", "text": "нет эмоции question" } ] } } }
```

По нему HErPlan показывает значок на разговоре и на узле:

- **в игре** — перенесён и с тех пор не менялся;
- **изменён** — правили после переноса: время правки позже `at`;
- **ошибка** — в `problems` что-то есть; текст виден при наведении и в «Проверить диалог».

Время правки HErPlan ведёт только у графов с именем в игре: `edited` у графа, узла, реплики и варианта, `created` у узла (ISO 8601). Перемещение узлов, цвет, комментарий автора и заметка для перевода правкой не считаются.

## Переводы: `data/dialogue_translations.json`

Реплики и варианты на других языках игры, по их `id`. HErPlan показывает перевод рядом с репликой, только для чтения. Формат предложен HErPlan (в документе владельца он не задан):

```json
{
  "en": {
    "l1": "Who disturbed my rest?",
    "l3": { "text": "Leave while you can!", "at": "2026-11-12T10:00:00Z" }
  }
}
```

Ключ верхнего уровня — код языка (`en`, `de`, `pt-BR`…). Значение записи — строка или `{ "text", "at" }`; если `at` есть и реплику правили позже (поле `edited`), рядом с переводом написано, что реплику меняли после перевода. Остальные ключи и записи не строкой пропускаются.

## Кнопки в редакторе

- **Проверить диалог** — список того, обо что споткнётся игра: нет имени в игре у разговора или у того, на что он ссылается; пустая реплика, реплика без говорящего, реплика длиннее предела (считается текст без эффектов в скобках); выход в никуда, недостижимый узел, выбор без вариантов или с вариантами, которые все закрыты условиями; значения не из палитры; лицо, которого у персонажа нет; «кому» указывает на того, кто в разговоре не говорит; условие или эффект не разбирается, переменная не заведена; круг без единой реплики и выбора.
- **Задание для Claude** — кладёт в буфер обмена готовую фразу: что перенести (разговор, выбранный узел или реплику — с именами и номерами), путь к файлу графа и что изменилось с прошлого переноса. Пример: «Перенеси в игру разговор skeleton_talk (data/graphs/a2sc….json): изменены реплики l3, l7 узла «Приветствие», добавлен узел «Подношение»».
- **Просмотр как в игре** — у реплики и для всех реплик узла. С 0.8.1 — по числам палитры (`preview`): скорость и паузы после знаков препинания, слоги и слова по правилам игры, стиль реплики и пометки поверх него, эффекты букв и тряска экрана по формулам игры. Проигрывание считается от времени: «Сначала» начинает заново всё — метки, тряску, лицо; в просмотре всех реплик узла (с 0.8.2) — с первой реплики. Без палитры — числа игры на 11.11.2026 (32 знака в секунду). С 0.8.2, если в палитре есть шрифт (`preview.font`) и его картинка, — сцена как в игре: пузырь из девяти частей (`preview.bubble`: заливка `fill` с прозрачностью `alpha`, рамка и хвостик цветом говорящего, форма — `bubble` говорящего), над говорящим (пока цветной прямоугольник 16×24, спрайты — в 0.8.4); у рассказчика пузырь внизу посередине без хвостика. Буквы — атласом шрифта, с переносом по словам в ширину `preview.text.width`; бипы — голосом говорящего (`voices[].sound`) с высотой по букве; звук метки — `sounds[].sound`. Под сценой: ▶/⏸, «Сначала» (с первой реплики), ползунок времени, скорость ×0,5/×1/×2, звук вкл/выкл; в окне «Реплика» (двойной щелчок по реплике в узле или «развернуть») — ещё «весь узел» и ← → по репликам.
- **Копия узла** (Ctrl+C / Ctrl+V, Ctrl+D) — реплики и варианты копии получают новые `id`; метки на них, выход «перебили», выходы вариантов и `видел()` внутри скопированного переходят на новые `id`. Время правок не копируется.
- **Шаблон «разговор с напарником»** — правый щелчок по пустому месту холста: реплики напарника, выбор из трёх ответов, ответ напарника на каждый и конец. Тексты — заготовки на языке интерфейса.
- **Поиск по репликам** — по словам реплик и вариантов, по тому, кто говорит, и по тому, где используется переменная, предмет или персонаж (говорит, «кому», условие, эффекты, эффект в тексте, действие, запись отданного).
- **Текст разговора** — разговор простым текстом (`.txt`) в порядке, в котором он идёт от начала: «ИМЯ (указания): текст», метки между словами — в квадратных скобках, эффекты в фигурных скобках не пишутся; выбор — с номерами вариантов и тем, куда они ведут.
